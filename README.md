# Anteprima — nuovo sito dolphinmarine.it

Copia di sola visione del nuovo sito del **Cantiere Nautico Dolphin Marine**
(Melpignano, Lecce), pubblicata qui per poterla guardare da qualsiasi
dispositivo prima della messa online sul dominio.

- Non è il sito definitivo. Gli indirizzi canonici puntano già a
  `https://www.dolphinmarine.it` e `robots.txt` blocca i motori, così questa
  copia non viene indicizzata al posto del sito vero.
- Il modulo dei contatti qui non invia: ha bisogno di PHP, che GitHub Pages non
  offre. Sul dominio funziona.
- I sorgenti e le istruzioni stanno nel repository privato `dolphinmarine.it`.
